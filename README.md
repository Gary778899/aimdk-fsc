# AimDK FSC

## 项目工作流程

### 1. 本地修改与代码同步

在本地工作区修改代码、完成必要的静态检查后，在 VS Code 中依次运行：

1. `机器人：预览同步`：使用 rsync 的 `--dry-run` 查看待同步与待删除内容。
2. `机器人：推送工作区`：确认预览后，实际推送代码。

当前目标为 `agi@10.0.1.41:/home/agi/aimdk-fsc/`，具体连接与参数以
[.vscode/tasks.json](.vscode/tasks.json) 为准。
两个任务均使用 `--delete`，清理目标目录内本地已不存在且未被排除规则保护的内容。
保留现有排除项，不使用 `--delete-excluded`；`data/`、`log/`、`exports/`
已排除，不会随代码推送。受排除保护的旧构建和安装产物也不会因推送自动清理。

### 2. 容器内构建与验证

机器人宿主机的项目目录为 `/home/agi/aimdk-fsc`，通过目录绑定挂载至容器内同一路径；
数据目录为 `/home/agi/data-fsc`，也通过目录绑定挂载供容器使用。
按实际配置进入现有开发容器，在容器内构建、运行和测试依赖 ROS 2、SDK 或硬件的代码。
colcon 构建范围显式限定 `--base-paths src`，避免纳入 `extra/` 中的独立工程及同名包。

根据容器内构建和实机测试结果在本地继续修改，再次同步并验证。
进入容器的常用命令见下文；如容器名称或配置变更，先核对实际环境。

### 3. 下载数据并保存日志

1. 停止实验、自研节点和采集，等待录制文件关闭。
2. 在本地 VS Code 运行 `机器人：下载采集数据`。
3. 确认任务正常结束，核对本地会话文件，必要时读回数据；另行下载所需构建、调试和验证日志到本地 `log/`。

下载任务将 `agi@10.0.1.41:/home/agi/data-fsc/` 内的内容单向下载到
当前项目根目录的 `data/`，目录不存在时会创建。
它不删除机器人源文件或本地独有文件；使用 `--checksum` 比较已有文件内容，
同路径内容不同时更新本地文件。每次采集应使用不同的会话目录名，避免覆盖历史数据。
当前任务不下载日志，也不会自动触发清理。

### 4. 清理机器人工作内容

确认所需数据和日志已下载并核对，且没有自研节点继续使用相关目录后，
在本地项目根目录使用下文的清理命令：先预览，核对后再添加 `--execute` 实际清理。

脚本通过 SSH 在机器人宿主机清空 `/home/agi/aimdk-fsc` 和 `/home/agi/data-fsc`
的全部内容，包括隐藏文件及项目的 `build/`、`install/`、`log/`，保留两个根目录及权限。
绑定挂载使清理结果同时反映到容器内，无需进入、停止或删除容器。

下载与清理独立运行；脚本不检查下载结果、不停止节点、不自动使用 sudo。
权限不足、连接中断或子挂载点等错误可能导致部分删除，须检查输出，不能视为清理成功。

### 5. 下次使用

保留现有容器及挂载配置时，下次通电后重新同步代码，再在开发容器内重新构建 ROS 项目，
然后启动自研节点。清理已删除构建产物，不能只同步代码便直接运行；通常无需重新构建镜像或重新创建容器。

连接地址变更时，同时更新 `.vscode/tasks.json` 和 `scripts/robot_cleanup.py`。

## 常用命令

### 进入开发容器

在机器人宿主机执行；当前记录的容器名为 `aimdk-dev`。

```bash
podman exec -it aimdk-dev bash
```

### 预览机器人目录清理

在本地项目根目录执行，仅列出待清理内容。

```bash
python3 scripts/robot_cleanup.py
```

### 执行机器人目录清理

停止实验和采集、下载并核对数据及日志后，在本地项目根目录执行。

```bash
python3 scripts/robot_cleanup.py --execute
```
