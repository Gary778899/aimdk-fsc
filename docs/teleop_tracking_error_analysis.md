# 遥操跟随误差实验分析

适用版本与实验方法见[实验方案](teleop_tracking_error_experiments.md)。本文件统一记录各项实验的分析结论，后续结果按实验编号追加，注明分析日期、数据依据和验证范围。当前已完成实验A及实验C、D的探索性数据分析；实验C的完整姿态与重复覆盖、实验D的严格配对、实验B、E待完成。

## 实验A：IK与误差分解

分析日期：2026-11-05。依据：[全程结果](../exports/tracking_20261105_185655/A_full/summary.json)、[首条发布5秒后右臂结果](../exports/tracking_20261105_185655/A_right_after5s/summary.json)及对应原始日志。

右臂同模型IK位置残差最大为0.000026 mm，与原始在线IK记录一致；曲线因与几十毫米的误差共用纵轴而呈现为零，说明本段厘米级名义TCP任务误差无法由IK数值求解残差解释，但实体模型准确性仍待独立测量。

本会话实际开启补偿；右臂全程任务位置RMSE为14.67 mm，首条发布5秒后为10.71 mm、最大18.66 mm。全程补偿几何项与反馈相对发送目标的几何项RMSE分别为33.44 mm和43.29 mm，两项存在明显方向相抵；补偿收益仍需开关配对实验确认。

左臂全程未使能遥操，其近零IK残差来自保持原目标；右臂缺少Grip释放后的保持段，且历史日志缺少精确反馈关联与发布调用时间，本次尚不能分离静态偏差与动态滞后，后续按实验C、D、B推进。

验证范围：本地核对原始日志、CSV、统计结果及分析源码，确认IK残差一致、三项有符号位置分解闭合；未执行机器人构建、运行或测试。

### 静态片段结论

`430c6486`具有12.24 s连续保持，七轴理想目标完全不变，满足实验C的保持时长要求。[末5秒窗口结果](../exports/tracking_20261105_right_review/430c6486_static_last5s/summary.json)覆盖31.495–36.491 s，名义TCP任务位置RMSE为45.05 mm，有符号XYZ均值为`[-28.16, +12.45, -32.89] mm`。该窗口首、末约1秒的平均位置误差向量相差约0.067 mm，偏差持续且变化很小。

该窗口肩pitch、肩roll、肩yaw及肘关节的反馈减理想目标均值分别为`+1.80°、+3.02°、+2.25°、+3.25°`，其余三轴约为`-0.47°、+0.42°、-0.19°`。497条HAL命令反馈的位置与固定发送目标逐轴一致；arm反馈源时间持续推进，未记录反馈校验错误。腰反馈位置不变，骨盆IMU姿态相对窗口首帧的最大旋转变化约0.015°。这些证据支持本姿态存在关节执行／保持环节的静态偏差，动态滞后不能单独解释该窗口误差；具体成因仍需补偿配对及不同姿态、到达方向复测。

`ec3dd521`的两段保持分别为5.48 s和3.75 s，对应第一段末5秒及第二段全段的位置RMSE为74.78 mm和43.74 mm；`c205d2ff`保持4.46 s，全段RMSE为51.96 mm。这些窗口的理想关节目标均完全不变，可保留为短时保持观测，尚未达到实验C要求的10 s保持。

### 可用范围与后续补测

四次会话的已发布目标中，同模型IK位置残差最大约0.000040 mm，仍远小于任务误差。末次因局部IK无解中止属于目标求解失败，需与此前已接受解的微小残差分开看；现有记录不能据此认定为工作空间边界。

本批数据可以确认无补偿时存在持续的名义TCP静态偏差。全程统计混合了运动、初始偏差和保持阶段，不能直接当作动态跟随性能，也不能与实验A中不同目标、开启补偿的会话直接比较收益。下一步优先保存`430c6486`保持姿态的理想关节目标作为参考，补齐相近姿态的重复、不同到达方向和补偿开关记录，再开展动态滞后拟合。

同一目录中重复运行产生了多份日志，各目录均沿用`pose1_rep1`标记，不能据此认定为三个姿态或三次标准重复。另三份遥操日志没有发布目标，可用于启动排查。同期`upper_body_home`日志包含一次记录、一次完成的运行，以及一次因右肩pitch误差`+7.965°`超过既有±5°门槛而在发布前退出的运行，单独保留为回归线索。

验证范围：在本地运行现有离线分析入口，核对七份遥操日志及三份home日志；四次有效遥操均可解析并生成右臂统计、CSV和曲线，新反馈标识与发布调用时间齐全。未执行机器人构建、运动或现场复测；本轮未拟合动态延迟，完整实验C及补偿收益尚待验证。

### 归因限制与补测

上述三个开启组保持目标相对关闭组保持目标的名义TCP位置差为122.8／145.3／141.4 mm，姿态差为26.2／31.3／47.2°，单轴最大理想关节差为37.8／44.6／38.4°。两组明显不是相同姿态；与此前四次无补偿会话的全部保持目标比较，三个开启组目标也未形成相同七轴姿态配对。姿态变化会改变重力、几何敏感度与执行偏差，因此当前数据支持跨姿态的改善趋势，严格收益仍需相同理想七轴目标、相同到达过程下的开关重复。开启组最长保持为8.82秒，后续还需补齐方案规定的10秒保持。

验证范围：本地使用现有离线入口完成两次全程和四个末5秒窗口分析，另计算保持目标FK及跨会话姿态差；未执行机器人构建、运行或现场复测，未拟合动态延迟。以上均为躯干系名义模型误差，实体TCP精度仍待独立测量。
