## 已确认事实

### 首帧后下沉

零增量实验中，motion_begin之前已记录的关节位置与各自采样起点一致。
首次观察到超过0.1°的关节变化在首帧记录后约41～44ms，随后约0.2～0.3秒内形成明显偏差。
该时间基于反馈接收时刻，不等同于硬件响应延迟。

| 约动作开始后0.3秒 | 补偿开 | 补偿关 |
| --- | ---: | ---: |
| 左/右肘增量 | +2.384° / +2.538° | +2.296° / +2.384° |
| 左/右肩roll增量 | −1.857° / +1.868° | −1.736° / +1.813° |
| 左/右腕Z变化 | −7.80 / −8.05mm | −7.04 / −7.39mm |

同时存在向内、向后偏移。关闭补偿后偏差基本持续至结束；开启补偿后有所回收。
X+20mm实验中同样观察到启动瞬态，因此该现象不依赖非零TCP请求。

### 首帧数值与反馈一致

关闭补偿的零增量测试，全部265帧14关节目标均与采样值相同；首帧与发布前最近反馈的最大差为0°。
开启补偿时理想目标仍全程不变，首帧与最近反馈的最大差仅0.000001665°；
两组最近反馈的记录时刻分别早于首帧8.47ms、5.51ms。
按关节名称和SDK槽位检查，未发现单位转换、左右顺序或关节重排导致的大目标差。
源码直接将rad目标写入arm_pos；尚未录制订阅端实际接受的底层目标。

### 补偿有效性与启动覆盖不同

X+20mm配对的起点最大关节差约0.264°，代码和模型版本一致。
开启补偿后，左/右终点位置误差分别下降约67%/62%，但X实际行程仍只有约16.04/13.62mm。
肩roll、肘的理想目标误差明显改善，肩pitch和右腕yaw改善较小。

补偿按整段5秒轨迹的五次进度引入。约0.3秒时只有最终偏置的0.16～0.17%，
因此当前开启补偿不能避免前0.3秒的下沉。
零增量的开启与关闭两组起点最大关节差约0.912°，不作为严格同起点的定量收益配对。

### 模式与来源未记录到切换

3479378a、a9046813和两次零增量日志的全部mc反馈中：
action_desc保持UPPERBODY_REMOTE_SPLIT、status=100，input_source保持空名称、priority=0、timeout=0。
未记录到公开模式或输入源切换；内部上肢保持路径是否改变仍不可见。
本地SDK将原生上肢source描述为任意非空字符串，官方示例直接赋值并发布，未注册输入源。
当前不能用通用MC优先级仲裁规则推定此接口内部行为，亦无改source即可修复的依据。

### 日志与完成标志的边界

- 上肢脚本与采集器默认读取相同的SDK双臂、夹爪反馈话题。
- 提前订阅已覆盖模式查询阶段；单线程规划仍存在约1.6～1.9秒回调空窗，无法恢复其中的短暂变化。
- completed表示满足当前执行条件。2°动作小于±5°终点容差，不能只凭退出状态评价动作效果。
- 已分析样本未记录反馈错误或发布间隔中止；这不覆盖故障注入、断链及退出后保持行为。
- SDK、固件版本和现场负载说明仍为unknown；记录的零附加质量不代表现场负载已核实为零。

## 根因假设与待核实项

当前工作假设：开始接收外部位置命令后，底层带载保持的受力平衡发生变化。
实际位置不一定等于先前内部位置参考；原保持可能包含重力前馈、积分项或位置偏置。
若新目标替换了内部参考或改变了这些支撑项，即使目标等于实际角度，仍可能下沉后形成新的负载偏差。
该解释符合现象，但尚无原厂内部目标、力矩或前馈记录，不能表述为已确认的重力补偿切换。

其他待区分项为反馈与命令的校准/零点语义、其他发布者及实际命令仲裁。
当前已排除本次脚本首帧大位置差、非零TCP路径及补偿突然全量加入作为必要触发条件。

优先向厂商核实：

1. URS无外部命令时如何保持双臂，首次及中断后重新收到命令时如何接入。
2. arm_pos是否为期望实际角度，是否已包含原厂重力前馈，是否要求外部偏置。
3. 接入前后是否重置内部目标、积分项或改变刚度/前馈，能否只读获取这些内部量。

下一次执行验证需覆盖持续会话中的保持、Grip重新接管及停止发布后的表现。
根因未明时，不直接通过全量首帧补偿、改source或扩大容差掩盖启动变化。

## 已有验证能支持什么

包内模型/限位适配、实际反馈FK/IK、18条小范围离线连续轨迹、完整原生消息发送、
双臂同帧单次平移、部分关节与夹爪动作已有可复核日志。
18条离线回放共4518帧均accepted，单侧计算中位值约2.8ms；
左侧最大16.32ms、右侧最大3.86ms，含候选检查及FK，使用腕原点TCP。
这些回放分侧进行，不能据此宣布双侧在线IK加反馈、补偿、发布及写盘在20ms内全部完成。

尚无完整双臂逐帧在线目标执行、omnipicker TCP下的连续回放、PICO输入/重定位/失联验证，
纯旋转与完整位姿实机覆盖、退出保持及实体精度验收也未完成。
人工验收报告部分填写accepted，但覆盖和观察记录不足以宣布第一阶段全部完成。
