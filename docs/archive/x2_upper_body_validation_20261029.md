# X2 Ultra 上肢 IK 与位置偏置补偿验证汇总

实验日期：2026-10-29。整理日期：2026-10-30。
依据为用户回传的机器人 Humble 容器执行日志及已有本地离线分析，不是本次重新执行机器人验证。
日志保存在本地 `log/`，完整分析位于 `exports/`；两目录不纳入 Git，本文件保留结论与文件索引。

## 实施与验证顺序

1. 提取参考项目运动学算法，安装官方 X2 Ultra v1.3.0 URDF，统一关节名称、槽位和限位。
2. `upper_body_kinematics_check` 采集实际反馈快照，再关闭订阅完成 FK→IK→FK；
   肩 roll 边界调整后的 `SD_adjusted` 单快照双侧求解完成，异常计数0，无运动发布。
3. `upper_body_move` 对单个笛卡尔端点做局部 IK，再以关节五次插值执行；
   5mm 执行尝试曾被夹爪静止检查在发布前阻断，后续10mm、15mm执行完成。
4. `upper_body_line` 在运动前完成整条路径的连续局部 IK，5秒为251点，再以50Hz发布。
   运行期间按时间取规划目标并在相邻点间做关节插值，不在线逐周期求解 IK。
   两次早期尝试因规划后积压反馈超龄而在发布前退出；源时间刷新修正后10mm、20mm执行完成。
5. 显式启用位置偏置补偿，完成一次只读规划和10mm、20mm执行，并与此前无补偿记录比较。

## 补偿方式及对比结果

使用官方模型计算重力矩，由骨盆 IMU 四元数和具名三腰角换算躯干重力方向。
位置偏置为 `clip(τg/40, ±12°)`，随运动的五次进度从零引入，仅作用于所选臂。
通过原生位置接口发送，不是直接下发重力补偿力矩。补偿默认关闭。

四次对比动作均为左臂 torso +X、5秒、腕原点 TCP。
下表为实际关节反馈经同源模型 FK 回算的终点指标。

| 指标 | 10mm无补偿 | 10mm有补偿 | 20mm无补偿 | 20mm有补偿 |
| --- | ---: | ---: | ---: | ---: |
| 距请求终点/mm | 14.849 | 3.678 | 15.110 | 5.350 |
| 相对起点姿态变化/° | 2.997 | 0.405 | 3.063 | 1.051 |

两组反馈FK终点误差均改善，但同幅度对照的起点位置相差28.40/23.12mm，
姿态相差6.02°/3.38°；每个配置每个幅度只有一次执行，补偿记录负载描述为unknown、
附加载荷模型为0kg，不能把全部差异归因于补偿。启动偏移仍存在。
反馈相对原IK目标更接近，并不表示相对实际发送值的底层伺服跟踪误差同步降低。
completed表示通过既有±3°关节条件，实体轨迹与末端精度仍需独立测量。
